# Womble number 1 branding pack

Open Womble-Brand-Guide.html for the self-contained eight-page guide, or use the PDF when present. Open implementation/voice-state-demo.html locally to preview the listening tilt.

Assets contain the original full-resolution raster artwork and approved design references. No true vector logo, exact custom font, 1-bit 256-dot thermal export, or indexed 256-colour export is claimed. These final production steps are documented in the guide. CSS motion works from the neutral portrait; the separate tilted image is a reference/static alternative.

The demo is visual only and activates no microphone. The brand guide covers the BOX-3 voice hub, re-flashed picture-frame dashboard and Bluetooth shopping-list printer.

The brand artwork (logo, mascot, device references and social preview) is AI-generated concept art.
